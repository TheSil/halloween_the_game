Scoring events

What every event in a match is worth: XP, match points and, for Michael, bloodthirst. For more about match points, see the Match Points tab.

  • XP and match points of kills and executions are then multiplied by their kill modifiers. Bloodthirst is not.
  • Plain names are the ones the game shows on the left of the screen when the event happens.
  • Names in grey italics are ours: the game does not show these events by name.
Bloodthirst meter

Each level of the meter is filled on its own: 200 for Level 1, then 315 more for Level 2, then 450 more for Level 3, 965 in total.
